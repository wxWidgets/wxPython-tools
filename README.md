This is the set of tools used during the wxPython build process that 
were formerly hosted at https://wxpython.org/Phoenix/tools/.  They were 
moved here to have them hosted by GitHub pages.

The cairo DLLs and headers bundled with wxPython on Windows are attached
to this repo's releases. They are built and published by the
"Build MSW cairo" workflow (.github/workflows/build-msw-cairo.yml).
